Restoration / Provenance

A source-grounded, functional, read-only reconstruction of the main IDunnoPoetry.com website, distinct from its historical phpBB forum and the modern RhymeMosaic literary canon.

Directly recovered

  • Original head.txt layout and navigation labels: fixed 775-pixel frame, 120-pixel sidebar and rotating 12-image corner
  • Original logo2.jpg, navigation icons and background images
  • All 106 original static poem .txt files, with matching index order from poetry.shtml
  • 18 original IDP1.jpg–IDP18.jpg artworks and gallery page assignments
  • Archived home announcement dated April 6, 2011
  • Selected FAQ entries and original novelty word lists

Reconstructed / changed

  • assets/css/site.css is newly written using authentic graphic assets and corroborating idp/style.css; the missing root stylesheet has not been impersonated
  • Database-dependent PHP replaced with static HTML and local JavaScript, no server or login required
  • Mobile-friendly layout, search, sorting, print style and reader mode added as explicitly modern conveniences
  • Outside ads, analytics, historical contact endpoints and third-party embeds excluded
  • Selected historical FAQ excerpts shown; private/personal passages not automatically republished

Not recovered from these two archives

  • The populated original Poems, Poems2, Rates or Rates2 production database
  • Actual ranked top ten, original numerical ratings, historical user-contributed poems, accurate original added dates and later works
  • The original site root style.css and navigation-linked links.shtml document
  • Production messageboard accounts/posts from the raw installation code; those are investigated separately in the museum project
Evidence discipline: The original poem texts are copied byte-for-byte into witnesses/poems/. The displayed versions only adapt line-breaking markup for safe browsers. Historical file timestamps are not dates of writing. Canonical RhymeMosaic texts were not modified. Full original archives remain separate and private.
