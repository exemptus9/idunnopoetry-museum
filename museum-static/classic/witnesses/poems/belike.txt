<br><h1>What Would It be Like?</h1><br>


What would life be like,<br>
If we had never met?<br>
Where would we both be,<br>
If there was nothing to forget?<br><br>

How would my life be,<br>
If we never got together?<br>
Would I still be happy,<br>
Or would I stay depressed forever?<br><br>

What would you be doing,<br>
If we had never talked?<br>
If I hadn't e-mailed you,<br>
Would it be my fault?<br><br>

How would I be different,<br>
If I had never met you?<br>
Would I be better or worse,<br>
Or would I ever get through?<br><br>

I think it's amazing,<br>
How one action can cause so much,<br>
How it changes your life,<br>
It almost seems like luck.<br><br>

But like you say so often,<br>
It's all part of God's plan,<br>
And I think now more than ever,<br>
That I truly understand.<br><br><br>
