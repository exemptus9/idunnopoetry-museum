## Publication privacy

Personal source documents, raw uploads, private correspondence, notebook review
queues, family/crisis drafts and raw databases stay outside this public repository
and every deployment directory. Uploading a file or confirming authorship is not
permission to publish it. New material is private by default; obtain explicit
publication approval before adding personal material. Preserve private originals
separately. Do not put private material behind CSS, a hidden route, client-side
passwords, or a browser-only admin toggle.

Run `python3 -m unittest discover -s scripts -p 'test_*.py'` before publishing.
The creative allowlist locks the retained public text. Never expand it merely to
make a failed privacy test pass. Check `public/` as well as `museum-static/`.
